Instalar el certificado del proxy
Este certificado permite que FPGate revise las imágenes de las páginas seguras (HTTPS) del dispositivo de prueba. Solo necesitas hacerlo una vez.
Instala este certificado únicamente en el dispositivo de prueba destinado para este proyecto. No lo compartas ni lo instales en dispositivos personales.
fpgate-ca.crt
Autoridad certificadora (CA) pública de FPGate
Descargar certificado
Certificado descargado. Sigue los pasos a continuación para instalarlo.
Pasos de instalación (Windows y Chrome)
1
Descarga el certificado
Usa el botón de arriba para guardar el archivo fpgate-ca.crt en el dispositivo de prueba.
2
Abre el archivo descargado
Busca fpgate-ca.crt en la carpeta de descargas y haz doble clic. Se abrirá una ventana con los datos del certificado; pulsa Instalar certificado…
3
Instálalo como certificado de confianza
Elige Usuario actual y pulsa Siguiente. Luego selecciona Colocar todos los certificados en el siguiente almacén, pulsa Examinar y elige Entidades de certificación raíz de confianza. Pulsa Siguiente y Finalizar.
4
Confirma la advertencia de seguridad
Windows avisará que vas a instalar un certificado de una autoridad desconocida. Es lo esperado: FPGate es la autoridad de este proyecto. Pulsa Sí.
5
Abre Chrome conectado a FPGate
Cierra todas las ventanas de Chrome. Pulsa las teclas Windows + R, escribe el siguiente comando y pulsa Enter:
chrome.exe --proxy-server="{{PROXY_ADDR}}"
Solo esa ventana de Chrome pasa por FPGate; el resto del equipo no se ve afectado.
6
Comprueba que funciona
En esa ventana de Chrome abre una página segura, por ejemplo https://www.wikipedia.org. Debe cargar con el candado, sin avisos de privacidad. Si Chrome muestra «Tu conexión no es privada», revisa que el certificado quedó en Entidades de certificación raíz de confianza y vuelve a abrir Chrome con el comando del paso 5.

Si el equipo tiene un antivirus o un control parental que revisa el tráfico HTTPS, puede mostrar su propio error de certificado; en ese caso desactiva esa revisión para el dispositivo de prueba.
